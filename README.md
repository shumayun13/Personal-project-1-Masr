# For Haya — A Midnight Drive

A single-file, mobile-friendly apology website. Dark midnight colors, a cute car driving on an animated road, crescent moon, Egyptian flag, chocolates, and a clickable apology letter. A little plane remains in the sky as a nod to aviation. No hearts, libraries, accounts, or external assets.

## Preview locally

Double-click `index.html` to open it in a browser. Click the envelope, chocolate button, and surprise note.

## Host on GitHub Pages

1. Create a public repository (e.g. `for-haya`) on GitHub.
2. Upload `index.html` to the repository root.
3. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Visit `https://YOUR-USERNAME.github.io/for-haya/` once GitHub Pages has deployed.

## Personalize later

Edit the paragraphs immediately below `<!-- PERSONALIZE THESE PARAGRAPHS WHEN YOU'RE READY. -->` in `index.html`. You can also change the title, ticket fields, and button wording. The HTML file contains all styles and scripts, so nothing else must be uploaded.

The site is intentionally gentle: it acknowledges wrongdoing without asking Haya to forgive or reply.

## Music
The music button loads a privacy-enhanced YouTube embed for JadaL’s “Helwa Ya Baladi” (official artist upload). No copyrighted audio is included. The visitor must click Play; autoplay may be blocked by the browser. Internet access is required.
